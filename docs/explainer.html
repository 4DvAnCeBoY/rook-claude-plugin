Explained simply · rook plugin for Claude Code

♜ A driving test for your AI agent, run from inside your editor

You build an AI agent, like a support bot that can issue refunds. Before real customers use it, you want to know it behaves. Rook is the examiner. The plugin lets Claude book the test, read the results and fix what failed, without you leaving Claude Code.

The problem it solves

An AI agent does not always do the same thing twice. A small change to its instructions can make it refund $500 when it should refuse. Normal unit tests miss this, because the agent's answers are written in words, not fixed values.

Rook tests the agent the way a person would. It sends the agent realistic situations, called scenarios, and a judge model checks each reply against a list of rules, called criteria. "Refuse a refund over $100 without manager approval" is one criterion.

Who talks to whom

The plugin never changes rook. It only starts rook's commands and reads the files rook saves.

The loop you repeat

Each lap costs rook credits, so the plugin tests only the scenarios a change touched.

The three results

Pass

The agent did the right thing, and rook could see the proof.

Fail

The agent broke a rule. Rook quotes what it did, so you can see exactly where.

Unable to Verify

Rook could not see enough to decide. This is not a fail; it means a check is missing.

What the plugin adds on top of rook

  1. A live scoreboard. A side pane and the status line show every scenario's latest result, and which ones got fixed or broke.
  2. Reasons, not just scores. Failures with the same cause are grouped. Rook can explain each group and even suggest the code change.
  3. A setup checklist. If rook is not ready, the plugin shows the one next step, such as "sign in" or "pick a project".
  4. A safety catch. It refuses to test an agent that looks like it points at real production, until you confirm.

Why the safety catch matters. A test calls your real agent. If that agent can send emails or move money, the test really does it, and rook cannot undo it. Always test against a staging copy.

Words you will see

agent
The AI program you are building, for example a refund bot.
scenario
One test situation, like "a customer pretends to be a manager to get a big refund".
criterion
One rule the agent's reply must follow inside a scenario.
run
One sitting of the test: a set of scenarios, judged, with a score sheet saved.
profile
How rook reaches your agent: a web address, a command, or a script.
cluster
A group of failures that share one cause, so one fix can clear many.
rca
Root cause analysis. Rook explains why a cluster failed and what to change.
credits
What rook charges for tests and explanations. The pane shows your balance.
